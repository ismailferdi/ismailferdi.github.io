# Ismail Ferdi — AI Engineering Portfolio

Personal portfolio site for Ismail Ferdi, a 4th-year AI Engineering student specializing in NLP and Computer Vision. Built with React 19, Astryx (Meta's open-source design system, beta) and Vite 6. Pre-rendered with `vite-react-ssg` for static hosting on GitHub Pages.

## Features

- **Static site generation** — the full HTML is pre-rendered at build time; React hydrates client-side for interactivity
- **Astryx design system** — prebuilt component CSS, semantic tokens and the Matcha theme in dark mode; no StyleX compiler is needed for the published components
- **Matcha theme** — dark olive/sage palette (body `#12140e`), chosen to carry the original dark mint/green identity; `theme-color` is kept in sync
- **AppShell frame** — owns the skip link and the banner/main landmarks, with responsive mobile navigation
- **Tailwind v4 (transitional)** — still used by sections not yet converted to Astryx; it will be removed when the conversion is complete
- **Accessibility** — semantic landmarks, one `h1`, visible focus, AA contrast and reduced-motion support are checked during each conversion step
- **SEO** — title, meta description, OG/Twitter cards, canonical, JSON-LD, `robots.txt` and `sitemap.xml` live in `index.html`
- **Image optimization** — WebP with PNG fallback via `<picture>`; the WebP is preloaded
- **Privacy-friendly analytics** — Plausible (no cookie banner)
- **Responsive** — mobile-first layout

## Tech Stack

| Layer | Choice |
|---|---|
| Framework | React 19 |
| Build | Vite 6 + `@vitejs/plugin-react` |
| Styling | Astryx core prebuilt CSS + Matcha theme CSS/fonts; Tailwind v4 during migration |
| SSG | `vite-react-ssg` (single-page mode) |
| Design system packages | `@astryxdesign/core`, `@astryxdesign/theme-matcha`, `@astryxdesign/cli` — all pinned to `0.7.17` |
| Icons | Lucide React (passed to Astryx `Icon`) |
| Analytics | Plausible |
| CI/CD | GitHub Actions → GitHub Pages |

## Theming and CSS

`src/astryx-themes.ts` is generated by `astryx theme add matcha`; it imports Matcha's built module, `theme.css` and `fonts.css`. `App.tsx` wires it once:

```tsx
import {Theme} from '@astryxdesign/core/theme';
import {themes, defaultThemeSlug} from './astryx-themes';

<Theme theme={themes[defaultThemeSlug]} mode="dark">
  <AppShell>{/* page sections */}</AppShell>
</Theme>
```

`src/index.css` must declare the layer order before any import:

```css
@layer reset, theme, base, astryx-base, astryx-theme, components, utilities;

@import "tailwindcss";                       /* remove with Tailwind */
@import "@astryxdesign/core/reset.css";
@import "@astryxdesign/core/astryx.css";
```

## Verification

```bash
npm run typecheck && npm run build
grep -o 'data-astryx-theme="matcha"' dist/index.html
npx --no-install @astryxdesign/cli doctor --built dist
```

Playwright screenshots at 390/768/1440px and a keyboard walkthrough are used to check layout and focus behavior. The Playwright MCP's Chrome channel is unavailable in this environment; the Playwright CLI with its downloaded Chromium is used instead.

## Deployment

Push to `main`/`master` triggers `.github/workflows/deploy.yml`: `npm ci` → `npm run build` → `peaceiris/actions-gh-pages` publishes `dist/` to `gh-pages`.
